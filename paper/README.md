# Paper assets

This directory contains the current manuscript source, a review PDF, final figure exports, verified reference text, and the scripts used to assemble figures.

## Asset status

- `PRUSCOPE_MANUSCRIPT_SOURCE.md` is the editable source of the current scientific text.
- `PruScope_Plant_Phenomics_Manuscript.pdf` is the visually checked review rendering.
- `figures/` contains the final main and supplementary figures in the available PNG/PDF/SVG formats.
- `scripts/` preserves generation logic for review. Some scripts require restricted source images, per-image predictions, or the complete internal metric registry and therefore are not runnable from this lightweight repository alone.

Figure scripts are included for methodological transparency, not represented as a standalone clean-room figure package. Quantitative source tables available for redistribution are in `../evidence/metrics/`. All paper assets are covered by `../release/SHA256SUMS`.

The final journal-formatted source, declarations, exact repository commit/tag/DOI, and publication license will be updated only after the corresponding author approves the stable release.
