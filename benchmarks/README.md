# Benchmark contract

The manuscript benchmark fixes task data, source-group splits, canvas size, epoch budget, seed set, and evaluation code. Comparator initialization differs from PruScope's fruit-domain teacher, so results are described as same-task/same-budget rather than identical-pretraining architecture isolation.

Core aggregate results are in `../evidence/metrics/competitive_detector_benchmark.json`. A future stable model release must add a redistributable image fixture, approved weights, clean-machine runtime command, warm-up/repeat policy, framework/CUDA versions, and machine-readable raw timing records.
